# Experiments

<!--
HOW TO USE THIS FILE:
This is the pre-registration log for your N-of-1 experiments. Every analysis skill in PHG ends
with testable hypotheses; this file is where hypotheses become designed tests instead of vibes.

The rules that make this work:
1. Design BEFORE you start. The success criterion, outcome metric, and evaluation date are
   written down before the intervention begins. No moving goalposts.
2. One variable at a time. An experiment that changes three things answers nothing.
3. Entries are append-only except the Status and Result fields. The design is never edited
   after the experiment starts — if the design was wrong, close the experiment and design
   a new one.
4. A negative result is a result. "No effect detected" kills a hypothesis and saves you
   money and attention. Log it with the same care as a win.

The EXPERIMENT skill (skills/EXPERIMENT.md) designs entries for this file and evaluates them
against their own pre-committed criteria when the evaluation date arrives.
-->
